How it works

Four AssemblyAI products, four jobs.

🎧 The headset

Voice Agent API
  • Two live sessions over one WebSocket each
  • Client tools revealed per step with session.update
  • reply.create, hold mode, semantic barge-in

👂 The ears

Universal-3 Pro streaming, inside the agent
  • keyterms + transcription prompt for SKUs
  • voice_focus far-field for a noisy floor
  • Pinned end-of-turn: 1.6 s to voice

📼 The black box

Sessions API
  • Stereo recording (picker L, agent R)
  • Conversation timeline per shift
  • Audit trail behind every pick

🔍 The auditor

Universal-3 Pro pre-recorded
  • Multichannel re-transcription
  • Re-checks every check-digit read
  • Sentiment + key phrases per shift

Browser

  • AudioWorklet capture + ring-buffer playback, 24 kHz PCM16
  • The shift state machine owns every fact

Node server

  • Single-use tokens; the API key never reaches the browser
  • Shift report + second-pass analysis endpoints

Honest limits

What this build is, and what it isn't yet.

  • The warehouse is a seeded simulation: no WMS connector yet
  • Recorded demo voices are synthesized; the live app takes any mic
  • 1.6 s to voice is slower than a legacy system's beep, so Tote plays an instant "heard you" tick
  • Our account has no LLM Gateway access, so shift notes are rule-based
  • Session pricing means scoping sessions to active picking, not whole shifts
  • One picker in the demo; the desk agent is built to take several
